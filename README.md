# 🤖 AI Chat Assistant

A modern, feature-rich AI chat application built with React and Groq's Llama 3 API.

## 🚀 Live Demo
**[Try it live!](https://jovial-froyo-99c2a9.netlify.app/)**

## ✨ Features
- 💬 Real-time AI conversations powered by Llama 3
- 🎨 Dark/Light mode toggle
- 📝 Markdown rendering (code blocks, lists, formatting)
- 📋 Copy messages & full conversation
- ⌨️ Keyboard shortcuts (Enter to send)
- 🎯 Quick suggestion prompts
- ⚡ Smart error handling with retry
- 📱 Fully responsive design

## 🛠️ Tech Stack
- **Frontend:** React.js
- **AI Model:** Groq API (Llama 3.3 70B)
- **Styling:** Pure CSS with dark mode support
- **Deployment:** Netlify
- **Markdown:** React Markdown

## 🚦 Getting Started

### Prerequisites
- Node.js 14+
- Groq API key (free at console.groq.com)

### Installation
```bash
# Clone the repo
git clone https://github.com/siddhigupta5/ai-chat-assistant.git
cd ai-chat-assistant

# Install dependencies
npm install

# Create .env file
echo "REACT_APP_GROQ_API_KEY=your_key_here" > .env

# Run locally
npm start
```
